Fish Speech와 OpenAudio S1, 서비스와 뭐가 다른가

피쉬오디오 웹 서비스는 쓰기 편하고 최신 모델이 바로 반영됩니다. 오픈소스 버전은 직접 설치해야 하지만 사용량 제한이 없고 데이터가 내 PC를 떠나지 않습니다.

필요한 사양

  • GPU: NVIDIA GPU 권장. 공식 README는 S2-Pro가 소비자용 GPU에서 돌릴 수 있는 크기라고만 밝히고 있고, 필요한 VRAM은 모델 버전마다 다르니 README를 확인하세요. CPU만으로도 되지만 생성 속도가 수십 배 느립니다.
  • OS: 윈도우·리눅스·맥 모두 가능. 맥은 애플 실리콘에서 동작하지만 속도가 떨어집니다.
  • 디스크: 모델 파일 수 GB. 여유 20GB.
  • 소프트웨어: Python, Git, CUDA(엔비디아). 도커 이미지를 쓰면 의존성 문제가 줄어듭니다.

설치 순서

명령어와 모델명은 깃허브 README가 기준입니다. 버전이 자주 바뀌므로 이 글은 흐름만 정리했습니다. 정확한 명령어는 README를 그대로 따르세요.

  1. 저장소 받기깃허브에서 fish-speech 저장소를 클론합니다.
  2. 가상환경·의존성파이썬 가상환경을 만들고 requirements를 설치. CUDA 버전과 PyTorch 버전을 맞추는 것이 가장 자주 막히는 지점입니다.
  3. 모델 다운로드허깅페이스에서 공개 모델 가중치를 받습니다. 라이선스 동의가 필요할 수 있습니다.
  4. 웹 UI 실행제공되는 웹 UI 스크립트를 실행하면 브라우저에서 서비스와 비슷한 화면이 열립니다.
  5. 한국어 테스트한국어 문장을 넣어 생성. 서비스 버전과 같은 텍스트 표기 요령이 그대로 적용됩니다.

로컬에서 목소리 복제

웹 UI에서 참조 음성 파일을 올리면 그 목소리로 생성됩니다. 서비스 버전과 같은 원리이고, 샘플 녹음 조건도 같습니다.

  • 참조 음성: 10~30초 평서문, 잡음 없는 WAV.
  • 프롬프트 텍스트: 참조 음성의 실제 대사를 함께 넣으면 정확도가 올라갑니다.
  • 한계: 서비스의 최신 복제 기능이 오픈소스에 늦게 반영되거나 빠질 수 있습니다.

라이선스와 상업적 이용

오픈소스라고 전부 상업적 이용이 되는 것은 아닙니다. 2026년 11월 깃허브 기준 코드와 모델 가중치는 'Fish Audio Community License', S2-Pro 가중치는 'Fish Audio Research License'로 배포됩니다. 상업적으로 쓰기 전 저장소의 LICENSE 파일과 모델 카드의 조건을 직접 확인하세요.

  • 개인·연구: 대부분 문제없음.
  • 상업적 이용: 모델 가중치 라이선스 확인 필수. 비상업 조건이면 서비스 유료 플랜을 쓰는 것이 안전합니다.
  • 서비스에 내장: API 쪽이 라이선스·유지보수 모두 단순합니다.

설치가 부담되면 서비스 버전이 답입니다

같은 모델 계열을 설치 없이 바로 씁니다. 대량 생성이 필요해지면 그때 로컬을 고려해도 늦지 않습니다.

자주 묻는 질문

Fish Speech와 피쉬오디오는 같은 건가요?

Fish Speech는 오픈소스 모델, 피쉬오디오(fish.audio)는 그 모델을 만든 팀의 웹 서비스입니다. 서비스가 더 최신 모델을 씁니다.

OpenAudio S1은 뭔가요?

Fish Speech 계열의 후속 모델명입니다. 이후 S2-Pro 등 새 모델이 나왔으니 정확한 버전과 공개 범위는 깃허브·허깅페이스에서 확인하세요.

GPU 없이도 되나요?

CPU로도 실행되지만 매우 느립니다. 실사용은 NVIDIA GPU가 필요합니다.

한국어 품질이 서비스와 같나요?

같은 계열 모델이라 비슷하지만, 서비스가 더 최신 모델을 쓰는 시기에는 차이가 납니다.

상업적으로 써도 되나요?

모델 가중치 라이선스를 확인해야 합니다. 조건이 불분명하면 서비스 유료 플랜이 안전합니다.
