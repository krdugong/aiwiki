일레븐랩스 어떻게 써요?

elevenlabs.io에 가입하고 Text to Speech 화면에서 글을 넣고, 목소리와 모델을 고른 뒤 생성하면 됩니다. 한국어는 따로 설정할 것 없이 한국어 글을 넣으면 한국어로 읽습니다.

  1. 가입: 구글 계정으로 1분, 카드 불필요
  2. 목소리: Voice Library에서 언어를 Korean으로 걸러 고르기
  3. 모델: 최신 Eleven v4(웹 한 번에 1만 자) 또는 다른 모델(5천 자)
  4. 생성 후 다운로드. 같은 조건이면 2시간 안에 2번 무료 재생성

영상으로 보기 (4분)

이 글의 순서 그대로 화면을 녹화한 영상입니다. 가입부터 결제(USD)와 해지까지 한 번에 보고 따라 하면 더 빠릅니다.

1. 가입

elevenlabs.io에서 Sign up을 누르고 구글 계정이나 이메일로 가입합니다. 카드 등록 없이 무료 플랜(월 1만 크레딧)으로 시작합니다.

메뉴가 영어라 처음엔 낯설 수 있습니다. 왼쪽 사이드바에서 Text to Speech(글을 음성으로), Voices(목소리), Studio(긴 글), Dubbing(더빙)만 알면 대부분의 작업이 됩니다.

2. 한국어 목소리 고르기

  • Voices → Voice Library(Explore)로 들어가 언어 필터를 Korean으로 둡니다.
  • 성별·나이·용도(내레이션, 대화, 광고 등)로 더 좁히고, 미리듣기로 톤을 확인합니다.
  • 마음에 드는 목소리는 내 목소리 목록에 추가해 두면 다음부터 바로 고를 수 있습니다. 무료 플랜은 커스텀 목소리 슬롯이 3개입니다.
  • 내 목소리로 읽게 하고 싶다면 목소리 복제가 필요합니다(Starter부터). 일레븐랩스 목소리 복제 글에 정리했습니다.

3. 글 넣고 생성하기

  • Text to Speech 화면 입력칸에 대본을 붙여 넣습니다.
  • 목소리: 방금 추가한 한국어 목소리를 고릅니다.
  • 모델: 최신 Eleven v4는 감정 표현이 가장 풍부하고 웹에서 한 번에 1만 자까지 넣을 수 있습니다. 다른 모델은 한 번에 5천 자입니다. 일레븐랩스 공식 문서 기준 v4 계열은 한국어를 포함해 90개 이상 언어를 지원합니다.
  • 설정: 모델마다 조절 항목이 조금 다릅니다. 톤이 들쭉날쭉하면 안정성 쪽으로, 너무 밋밋하면 표현력 쪽으로 옮겨 보세요.
  • Generate를 누르면 바로 생성됩니다. 웹에서는 모델과 상관없이 1자 = 1크레딧이 빠집니다.

4. 다운로드와 재생성

  • 생성된 음성은 플레이어 옆 다운로드 버튼으로 받습니다. 크레딧은 다운로드가 아니라 생성할 때 빠집니다.
  • 같은 글·목소리·모델이면 2시간 안에 두 번까지 무료로 다시 생성됩니다. 마음에 안 들면 글을 고치기 전에 재생성부터 해 보세요.
  • 무료 플랜으로 만든 음성은 상업적으로 쓸 수 없고, 공개할 때 제목에 출처('elevenlabs.io' 또는 '11.ai')를 넣어야 합니다. 자세한 조건은 일레븐랩스 무료 글에 있습니다.

긴 글은 Studio

유튜브 롱폼, 강의, 오디오북처럼 긴 대본은 Studio(긴 오디오 작업 공간)를 씁니다. 장·문단 단위로 나눠 생성하고, 틀린 문장만 골라 다시 만들 수 있어 관리가 쉽습니다. 무료 플랜은 프로젝트 3개, Starter부터 20개입니다.

영상 더빙

Dubbing에 영상 파일이나 링크를 올리면 원래 목소리 톤을 살린 채 다른 언어로 바꿔 줍니다. 한국어 영상을 영어·일본어로 내보낼 때 씁니다. 크레딧은 원본 1분·언어 1개당 2,000(워터마크)~3,000크레딧이 듭니다. 전문 용어가 많으면 번역 결과를 한 번 검수하세요. 더빙 도구 전반은 AI 더빙 글에서 비교했습니다.

한국어가 어색할 때

  • 숫자·영어 약어는 한글로 풀어 쓰세요. 'AI'는 '에이아이', '2026년'은 '이천이십육 년'처럼 쓰면 읽기가 안정됩니다.
  • 문장을 짧게 끊고 쉼표를 넣으면 호흡이 자연스러워집니다.
  • 목소리를 바꿔 보기: 같은 글이라도 목소리에 따라 한국어 자연도가 크게 다릅니다. 한국어 원어민 샘플로 만든 목소리를 고르세요.
  • 모델 바꿔 보기: 감정이 과하면 다른 모델로 생성해 비교해 보세요.

자주 묻는 질문

일레븐랩스 한국어 설정은 어디서 하나요?

따로 언어 설정이 없습니다. 한국어 글을 넣으면 한국어로 읽습니다. 자연스러운 결과를 위해 Voice Library에서 언어 필터를 Korean으로 두고 한국어 목소리를 고르세요.

한 번에 몇 자까지 넣을 수 있나요?

웹에서 Eleven v4 모델은 한 번에 1만 자, 다른 모델은 5천 자까지입니다. 더 긴 글은 Studio에서 나눠 만듭니다.

다시 생성하면 크레딧이 또 빠지나요?

같은 글·목소리·모델이면 2시간 안에 두 번까지 무료로 다시 생성됩니다(웹 기준, API 제외).

일레븐랩스 앱도 있나요?

있습니다. 일레븐랩스 공식 앱이 iPhone·Android용으로 나와 있습니다. 대본 작업과 다운로드는 웹이 더 편합니다.
