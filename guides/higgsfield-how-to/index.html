힉스필드 앱·어플, 있나요? (아이폰·안드로이드)

없습니다. 힉스필드는 '웹과 모바일 브라우저에서 동작한다'고 안내하며 공식 iOS·안드로이드 앱을 내놓지 않았습니다. 구글 플레이에 보이는 'Higgsfield AI'(개발자 Abiara) 앱과 APK 사이트는 힉스필드와 무관합니다. 결제·계정 정보를 넣지 마세요.

  • 아이폰: 사파리에서 higgsfield.ai 접속 → 공유 → 홈 화면에 추가. 앱처럼 씁니다.
  • 안드로이드: 크롬에서 접속 → 메뉴 → 홈 화면에 추가.
  • 힉스필드 앱스(Apps): 사이트 안의 '앱' 메뉴는 사용자가 슈퍼컴퓨터로 만든 웹 앱 모음이지 설치형 앱이 아닙니다.
  • 젠주츠 어플: 젠주츠도 웹 기능입니다. 별도 앱 아님.

가입과 한국어 설정

  1. 접속higgsfield.ai (또는 higgsfield.ai/ko). 'higgsfield.com'이 아닙니다.
  2. 가입오른쪽 위 Sign up → 구글 계정. 카드 등록 없이 무료 플랜.
  3. 한글언어 메뉴에서 한국어 선택. 메뉴·요금제·아카데미가 한글로 나옵니다. 프롬프트는 영어 권장.
  4. 플랜영상을 만들려면 Starter 이상. 제휴 링크로 로그인하면 3시간 동안 할인가.

첫 영상 만들기 5단계 (10분)

  1. 사진 준비제품이나 인물 사진 1장. 배경 단순, 피사체 중앙, 밝은 조명.
  2. 모델 선택처음엔 기본 추천 모델. 인물 동작은 클링 계열, 음성까지 필요하면 비오 3.1, 긴 컷은 시댄스 2.5.
  3. 프리셋 선택제품은 Orbit·Dolly In, 인물은 Crash Zoom, 공간은 Crane Up. 미리보기로 확인.
  4. 프롬프트피사체·동작·조명·분위기만 영어 한 줄. 카메라 지시는 넣지 않습니다.
  5. 생성·저장5초, 720p로 먼저. 마음에 들면 1080p·10초로 재생성. 다운로드 아이콘으로 MP4 저장.

할인 적용 상태로 첫 영상을 만들어 보세요

제휴 링크로 로그인하면 3시간 동안 최대 50% 할인. Starter로 시작해 위 5단계를 따라 하면 10분 안에 첫 영상이 나옵니다.

크레딧 확인과 아끼는 법

  • 확인: 오른쪽 위 잔여 크레딧 표시. 생성 버튼 옆에 이번 생성의 소모량이 뜹니다.
  • 테스트는 저렴하게: 5초·720p·Lite/Turbo 모델로 구도를 잡고, 최종본만 1080p·상위 모델.
  • 무제한 창: Plus 이상이면 무제한 모델 창의 이미지 모델로 참조 이미지를 무한 생성.
  • 이월 없음: 월말에 남으면 사라지니 월말에 테스트를 몰아서.

자주 막히는 지점

  • 생성 버튼이 안 눌림: 무료 플랜(크레딧 0)입니다. 영상은 유료.
  • 검열 거부: 타인 얼굴·유명인·선정적 내용은 모델별 필터에 걸립니다. 본인 또는 허락받은 사진만.
  • 손가락·글자 변형: 모델을 바꾸거나 참조 이미지를 더 선명한 것으로.
  • 한국어 프롬프트 결과 흔들림: 영어 한 줄로 바꾸세요.

자주 묻는 질문

힉스필드 앱이 있나요?

공식 앱은 없습니다. 아이폰·안드로이드 브라우저에서 higgsfield.ai를 쓰고 홈 화면에 추가하면 앱처럼 됩니다. 스토어의 동명 앱은 공식이 아닙니다.

힉스필드 사이트 주소는?

higgsfield.ai입니다. 한국어 UI는 higgsfield.ai/ko입니다.

힉스필드 한글 설정은 어떻게 하나요?

언어 메뉴에서 한국어를 고르면 됩니다. 프롬프트는 영어가 더 안정적입니다.

힉스필드 무료로 영상을 만들 수 있나요?

무료 플랜은 크레딧이 0이라 영상 생성이 안 됩니다. Starter 이상이 필요합니다.

힉스필드 만드는 법 중 제일 쉬운 건?

사진 1장 + 카메라 프리셋 + 짧은 영어 프롬프트입니다. 프롬프트 없이 프리셋만으로도 결과가 나옵니다.
