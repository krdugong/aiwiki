소울 2.0이란

힉스필드가 직접 만든 이미지 생성 모델입니다. 미드저니처럼 예술적 범용성보다 '잡지 화보 같은 실사 인물·패션·제품'에 집중했습니다. 시대감성 프리셋(Y2K·필름·에디토리얼 등)이 있어 프롬프트를 길게 쓰지 않아도 톤이 잡힙니다.

소울 2.0 사용법 5단계

  1. 이미지 메뉴 → Soul 2.0모델 목록에서 Soul 2.0 선택.
  2. 프리셋에디토리얼·필름·스튜디오 등 톤을 먼저 고릅니다. 결과 차이가 가장 큽니다.
  3. 프롬프트인물(성별·나이·분위기) + 의상 + 장소 + 조명 순으로 영어 한두 줄.
  4. 참조·무드보드참고 사진을 올리면 구도·색감을 따릅니다. 여러 장을 무드보드로 묶어 톤 고정.
  5. 생성·선택4장 생성 → 마음에 드는 것을 2K로 재생성 또는 영상 참조로 사용.

소울 ID: 같은 얼굴 고정하기

브랜드 모델이나 본인 캐릭터로 여러 컷을 만들려면 소울 ID가 필요합니다. 사진 20~80장을 올려 학습하면 이후 소울 이미지와 시댄스 영상에서 같은 얼굴이 유지됩니다.

  • 사진 조건: 다양한 각도·표정·조명, 얼굴이 선명한 20장 이상. 같은 사진 반복은 효과 없음.
  • 권리: 본인 또는 명시적 동의를 받은 인물만. 타인 사진 업로드는 약관(5.3) 위반.
  • 한계: 외부로 내보내기 불가. 힉스필드 안에서만 사용.
  • 무료: 캐릭터 생성 1회 체험. 실사용은 유료 플랜.

소울 → 영상: 소울 시네마 흐름

  1. 소울로 키프레임원하는 컷을 소울 2.0으로 생성.
  2. 영상 모델에 참조시네마 스튜디오(카메라·렌즈 선택) 또는 시댄스 2.5(소울 ID 요소 유지)에 참조로 입력.
  3. 프리셋·프롬프트Dolly In·Orbit 등 프리셋 + 짧은 동작 프롬프트.
  4. 컷 연결5~10초 컷 여러 개를 캡컷에서 이어 룩북 영상 완성.

자주 묻는 질문

힉스필드 소울 2.0은 뭔가요?

힉스필드 자체 이미지 모델로 패션 화보·실사 인물에 특화됐습니다. 프리셋 20종 이상, 2K 해상도, 장당 약 0.12크레딧입니다.

힉스필드 소울 ID는 어떻게 만드나요?

본인 또는 동의받은 인물 사진 20~80장을 올려 학습합니다. 이후 소울 이미지와 시댄스 영상에서 같은 얼굴이 유지됩니다.

소울 시네마는 뭔가요?

소울로 만든 이미지를 시네마 스튜디오나 시댄스 영상의 참조로 써서 화보 느낌 영상을 만드는 흐름을 가리킵니다.

소울 프롬프트는 한글로 써도 되나요?

입력은 되지만 영어가 안정적입니다. 프리셋을 먼저 고르면 프롬프트가 짧아도 됩니다.

무료로 소울을 쓸 수 있나요?

무료 플랜은 일부 이미지 모델 제한 사용과 캐릭터 생성 1회 수준입니다. 소울 대량 생성은 유료 플랜이 필요합니다.
