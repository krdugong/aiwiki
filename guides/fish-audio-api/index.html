API 키 발급과 요금

계정 설정의 API 메뉴에서 키를 만듭니다. 키는 한 번만 표시되니 바로 안전한 곳에 저장하세요. 요금은 생성 분량(바이트) 기준 종량제이고, 서비스 구독 플랜과 별도로 과금됩니다(s2.1-pro 기준 100만 바이트당 $15).

  • 키 관리: 용도별로 키를 나누고(블로그 자동화용, 테스트용) 유출 시 해당 키만 폐기합니다.
  • 요금 확인: s2.1-pro 기준 100만 바이트당 $15입니다. 모델별 단가는 공식 API 요금 페이지에서 확인하세요.
  • 한도: 분당 호출 제한이 있습니다. 대량 작업은 큐를 두고 순차 호출합니다.

파이썬으로 호출하기

흐름은 세 단계입니다. 정확한 엔드포인트와 파라미터 이름은 버전마다 바뀔 수 있으니 공식 API 문서를 기준으로 하세요.

  1. 요청 구성텍스트, 목소리 ID(reference_id), 출력 포맷(mp3/wav)을 JSON으로 만듭니다.
  2. 호출Authorization 헤더에 API 키를 넣고 TTS 엔드포인트에 POST.
  3. 저장응답 바이너리를 파일로 저장. 긴 대본은 문단 단위로 나눠 호출하고 합칩니다.

n8n으로 코드 없이 자동화

구글 시트에 대본을 적어 두면 자동으로 음성 파일이 드라이브에 쌓이는 워크플로입니다.

  1. 트리거구글 시트 '새 행 추가' 트리거 또는 매일 아침 스케줄.
  2. HTTP Request 노드피쉬오디오 TTS 엔드포인트로 POST. 헤더에 API 키, 본문에 대본과 목소리 ID.
  3. 파일 저장응답을 바이너리로 받아 구글 드라이브 업로드 노드로 저장.
  4. 알림완료 후 텔레그램·슬랙으로 파일 링크 전송.

같은 구조로 메이크(Make)에서도 됩니다. n8n 사용법은 별도 허브 페이지를 참고하세요.

자주 나는 오류

  • 401: API 키 오류. 헤더 형식과 키 유효성 확인.
  • 429: 호출 제한 초과. 간격을 두거나 큐 처리.
  • 긴 텍스트 실패: 한 번에 보내는 글자 수 제한. 문단 단위로 분할.
  • 한국어 깨짐: 요청 본문 인코딩을 UTF-8로 지정.

자주 묻는 질문

피쉬오디오 API 요금은 어떻게 되나요?

생성한 글자 수(또는 초) 단위 종량제이고 서비스 플랜과 별도입니다. 정확한 단가는 공식 API 요금 페이지를 확인하세요.

코드를 몰라도 API를 쓸 수 있나요?

n8n이나 메이크의 HTTP Request 노드로 코드 없이 연동할 수 있습니다.

목소리 복제도 API로 되나요?

됩니다. 참조 음성을 올려 목소리 ID를 만든 뒤 TTS 호출에 그 ID를 넣습니다.

한국어도 API에서 똑같이 되나요?

네. 텍스트 표기 요령(숫자 한글화 등)도 그대로 적용됩니다.

호출 제한이 있나요?

분당 호출 제한이 있어 대량 작업은 순차 처리해야 합니다.
