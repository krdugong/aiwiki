피쉬오디오 사용법 2026 — 가입부터 한국어 음성 다운로드까지 10분

가입부터 한국어 목소리 선택, 텍스트 입력 요령, 설정값, 다운로드, 영상 편집기에 넣는 법까지 화면 순서대로.

AI위키 에디터2026.10.30 업데이트읽는 시간 7분
30초 요약
  • 피쉬오디오(Fish Audio, 피시오디오로도 검색)는 가입 후 10분이면 한국어 음성 파일을 뽑을 수 있습니다.
  • 순서는 가입 → 한국어 목소리 선택 → 텍스트 입력 → 설정 → 생성 → MP3 다운로드. 카드 등록 없이 무료로 시작합니다.
  • 결과 품질은 텍스트 입력 요령이 절반입니다. 문장 단위 줄바꿈과 숫자 한글 표기가 핵심입니다.
  • 목소리 복제와 요금제는 별도 글에서 다룹니다. 이 글은 '처음 한 번 성공하기'가 목표입니다.

1. 가입과 첫 화면

fish.audio에 접속하면 오른쪽 위 Sign in 버튼이 있습니다. Google 계정으로 가입하면 카드 등록 없이 무료 플랜이 열립니다. 사이트 주소는 fish.audio 하나이고, 'fishaudio', 'fish audio' 어떻게 검색해도 같은 곳입니다.

첫 화면 왼쪽 메뉴에서 Text to Speech(음성 생성), Voices(목소리 라이브러리), Voice Clone(목소리 복제)만 알면 됩니다. 언어 설정에서 한국어를 고르면 메뉴가 한글로 바뀝니다.

2. 한국어 목소리 고르기

Voices 메뉴에서 언어 필터를 Korean으로 바꾸면 한국어 목소리 목록이 나옵니다. 각 목소리에 재생 버튼이 있으니 세 개 정도 들어 보고 고르세요.

  • 내레이션·강의: 차분한 톤, 속도 보통인 목소리. 긴 글에 피로감이 적습니다.
  • 쇼츠·광고: 밝고 빠른 톤. 짧은 문장에서 힘이 있습니다.
  • 주의: 라이브러리 목소리는 사용자가 올린 것이 많아 상업적 이용 허용 여부가 목소리마다 다릅니다. 설명란의 라이선스 표시를 확인하세요.

3. 텍스트 입력 요령 (결과의 절반)

같은 목소리라도 텍스트를 어떻게 넣느냐에 따라 결과가 크게 달라집니다. 테스트하며 확인한 규칙입니다.

  • 문장마다 줄바꿈: 한 문장이 끝나면 줄을 바꾸세요. 호흡과 쉼이 자연스러워집니다.
  • 숫자는 한글로: '2026년'보다 '이천이십육 년', '3.5%'보다 '삼 점 오 퍼센트'가 안전합니다.
  • 영어 약어는 발음대로: 'SaaS'는 '사스', 'API'는 '에이피아이'로 적으면 억양이 안정됩니다.
  • 쉼표로 쉼 조절: 강조할 단어 앞에 쉼표를 넣으면 잠깐 멈춥니다.

4. 설정값

처음에는 기본값으로 생성해 보고, 결과에 따라 하나씩만 바꾸는 것이 빠릅니다.

설정추천 시작값올리면내리면
속도 (Speed)1.0뉴스·정보 전달에 유리오디오북·감성 콘텐츠
감정 (Emotion)기본광고·쇼츠에 활기내레이션 안정
안정성 계열 옵션기본억양 일정, 단조로움표현 풍부, 가끔 흔들림

옵션 이름은 업데이트마다 바뀔 수 있습니다. 화면과 다르면 비슷한 이름의 메뉴를 찾으세요.

5. 생성과 다운로드, 영상에 넣기

Generate를 누르면 몇 초 안에 재생됩니다. 마음에 들면 다운로드 아이콘으로 MP3 또는 WAV로 저장합니다. 유튜브 편집용이면 MP3로 충분하고, 후반 작업이 많으면 WAV가 안전합니다.

  • 캡컷: 오디오 → 가져오기 → 파일 선택 후 타임라인에 올리고 자동 캡션을 돌리면 자막까지 끝납니다.
  • 프리미어·파이널컷: 미디어 가져오기 후 오디오 트랙에 배치. 음량은 -6dB 전후가 무난합니다.
  • 여러 문단: 긴 대본은 문단 단위로 나눠 생성하면 수정이 쉽고 실패 시 손실이 적습니다.

자주 묻는 질문

피쉬오디오 사용법이 어렵나요?

아닙니다. 가입 → 목소리 선택 → 텍스트 입력 → 생성 → 다운로드 다섯 단계이고, 한국어 메뉴로 바꿀 수 있습니다.

피쉬오디오는 한국어 목소리가 있나요?

있습니다. Voices에서 Korean 필터로 찾을 수 있고, 품질은 별도 글 '피쉬오디오 한국어 품질'에서 테스트했습니다.

생성한 음성을 유튜브에 써도 되나요?

본인이 복제한 목소리나 상업적 이용이 허용된 목소리는 됩니다. 라이브러리 목소리는 개별 라이선스 표시를 확인하세요.

앱이 있나요, 설치해야 하나요?

웹 서비스라 설치가 필요 없습니다. 모바일 브라우저에서도 동작합니다.

결과가 어색하면 어떻게 하나요?

대부분 텍스트 문제입니다. 문장 줄바꿈, 숫자 한글 표기, 영어 약어 발음 표기부터 바꿔 보세요.
