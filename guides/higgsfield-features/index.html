시네마 스튜디오 4.0

힉스필드의 대표 영상 도구입니다. 2026년 8월 12일 4.0으로 업데이트돼 한 번에 최대 30초, 1080p, 참조 이미지 50장, 템포 조절, 카메라 4종·렌즈 5종, 카메라 프리셋 30종 이상, 앞·뒤로 이어 붙이기(Extend)를 지원합니다. 이전 3.5는 15초·참조 9장이었습니다.

  • 사용법: 참조 이미지 업로드 → 카메라 타입·렌즈 선택 → 프리셋 → 길이·템포 → 생성. 프롬프트는 짧게.
  • 가격: 별도 요금이 아니라 크레딧 차감. 30초·1080p는 소모가 크니 10초로 구도를 잡고 늘리세요.
  • 버전 검색: '시네마 스튜디오 2.5/3.0'으로 검색되는 글은 구버전 기준입니다. 현재는 4.0.

팝콘 (스토리보드)

장면 일관성이 유지되는 스토리보드 프레임을 최대 8장 만드는 이미지 도구입니다. 수동·자동·인스타덤프 세 모드, 참조 4장. 만든 프레임을 클링·비오로 애니메이션화해 짧은 스토리 영상을 만듭니다.

  • 용도: 광고 콘티, 숏드라마 컷 기획, 캐릭터 시리즈.
  • 흐름: 팝콘 8프레임 → 마음에 드는 프레임을 영상 모델에 참조 → 컷 연결.

스픽 v2 · 립싱크 스튜디오 · 힉스필드 오디오

립싱크 스튜디오(2025년 9월)는 대본이나 음성 파일로 말하는 영상을 만듭니다. 자체 모델 스픽 v2 외에 lipsync-2, InfiniteTalk, 클링 아바타·립싱크, 비오 3를 고를 수 있습니다. 힉스필드 오디오는 보이스오버·목소리 복제·번역을 제공합니다(일레븐 v3, 미니맥스 스피치 등 외부 음성 모델 포함).

  • 한국어: 음성 모델별로 한국어 품질이 다릅니다. 내레이션은 피쉬오디오·일레븐랩스에서 만들어 음성 파일로 넣는 조합도 많이 씁니다.
  • 주의: 타인 얼굴·목소리는 약관 위반.

DoP (자체 이미지→영상 모델)

힉스필드가 직접 만든 이미지→영상 모델입니다. 키프레임 이미지가 필요하고 Lite·Turbo·Standard 등급이 있습니다. 2026년 1월 기준 720p 3초에 약 3/5/7크레딧으로, 외부 모델보다 저렴해 테스트용으로 적합합니다.

언리미티드 (무제한 모델 창)

Plus·Ultra·Team·Scale에 포함되는 기능으로, 지정된 모델을 기간 동안 크레딧 차감 없이 쓸 수 있습니다. 365일짜리 이미지 모델 창(시드림 5.0 Lite, FLUX.2 Pro, 나노바나나, GPT 이미지 등)과 7일짜리 플래그십 창(나노바나나 2/Pro, 클링 3.0 720p 등)이 있고, Team·Scale에는 시댄스 2.0/2.5 창이 들어갑니다. '힉스필드 시댄스 무제한'이 이것입니다.

  • 적용 범위: higgsfield.ai 웹에서만. MCP·CLI·캔버스·슈퍼컴퓨터에서는 크레딧 차감.
  • 변동: 대상 모델과 기간이 시기별로 바뀝니다. 결제 전 현재 창 목록 확인.
  • 환불: 무제한 같은 '접근 권한' 프로모션은 부여 즉시 환불 불가.

MCP · API · CLI · 클로드 연동

'클로드 힉스필드'로 검색되는 것이 이것입니다. 힉스필드 MCP 서버(mcp.higgsfield.ai/mcp)를 클로드의 커스텀 커넥터로 추가하면 클로드 대화 안에서 생성을 지시할 수 있습니다. CLI(npm i -g @higgsfield/cli)와 스킬(/higgsfield:generate, /higgsfield:soul-id), 애프터이펙트 플러그인(2026년 7월)도 MCP 기반입니다. 공개 API는 별도 요금 체계입니다.

  • 조건: MCP·API는 유료 플랜 필요, 항상 크레딧 차감(무제한 창 미적용).
  • 용도: n8n·메이크 워크플로에서 대본→영상 자동화, 대량 제품 컷 생성.
  • 주의: API 키는 용도별로 나누고 유출 시 즉시 폐기.

아카데미

2026년 7월 시작된 공식 무료 강의입니다. 'AI 크리에이션 첫걸음'(1시간 42분, PDF·수료증, 2026년 10월) 등 영상 강의는 무료이고, 과제 실습만 유료 플랜·크레딧이 필요합니다. 한국어 UI에서 '아카데미' 메뉴로 접근합니다.

자주 묻는 질문

힉스필드 시네마 스튜디오는 뭔가요?

카메라 타입·렌즈·프리셋을 골라 최대 30초·1080p 영상을 만드는 대표 도구입니다. 현재 4.0이고 참조 이미지 50장까지 넣을 수 있습니다.

힉스필드 언리미티드가 뭔가요?

Plus 이상 플랜에 포함된 무제한 모델 창입니다. 지정 모델을 기간 동안 크레딧 없이 쓰고, 웹에서만 적용됩니다.

클로드에서 힉스필드를 쓸 수 있나요?

네. 힉스필드 MCP 서버를 클로드 커스텀 커넥터로 추가하면 됩니다. 유료 플랜과 크레딧이 필요합니다.

힉스필드 팝콘은 뭔가요?

일관된 스토리보드 프레임을 최대 8장 만드는 이미지 도구입니다. 프레임을 영상 모델로 애니메이션화합니다.

힉스필드 레이어스는 뭔가요?

공식 도움말과 사이트에서 찾을 수 없는 명칭입니다. 캔버스나 다른 기능의 별칭이거나 커뮤니티에서 부르는 이름일 수 있습니다.
