러버블란

러버블(Lovable)은 자연어로 설명하면 리액트 기반 웹앱을 만들어 주는 AI 앱 빌더입니다. 화면 디자인, 기능 구현, 배포까지 채팅 안에서 끝나고, 수파베이스를 연결하면 로그인과 데이터 저장도 됩니다. 코드는 깃허브로 내보내 개발자에게 넘길 수 있습니다.

국내에서는 러버블, 바이브 코딩으로 검색되고, 개발을 모르는 기획자·마케터·소상공인이 '일단 돌아가는 것'을 만드는 데 가장 많이 추천됩니다. 전자책과 강의가 늘어나는 중입니다.

사용법 5단계

  1. 가입lovable.dev에서 구글 계정으로 가입. 무료 플랜은 하루 5크레딧(월 최대 30)입니다.
  2. 요구사항 작성첫 메시지가 가장 중요합니다. 목적, 페이지 목록, 각 페이지 기능, 디자인 톤을 한국어로 길게 적습니다.
  3. 생성 확인1~2분 안에 동작하는 앱이 나옵니다. 미리보기에서 눌러 보며 문제를 메모합니다.
  4. 수정 요청한 번에 여러 수정을 묶어 요청하면 크레딧이 절약됩니다. 'Try to fix'를 포함해 각 요청에 쓰인 크레딧은 응답 아래 Credits used에서 확인할 수 있습니다.
  5. 배포Publish 버튼으로 lovable.app 주소에 배포. 내 도메인 연결은 유료 플랜에서 됩니다.

영상으로 보는 사용법

국내 크리에이터가 올린 가이드 영상입니다. 글로 이해가 안 되는 화면 조작은 영상으로 확인하세요.

크레딧 아끼는 요구사항 작성법

같은 앱을 '짧은 요청 + 수정 10번'과 '긴 요청 + 수정 3번'으로 만들어 봤습니다. 후자가 크레딧을 절반 이하로 썼습니다.

  • 구조 먼저: 페이지 목록과 이동 흐름을 먼저 적습니다. 나중에 구조를 바꾸면 비용이 큽니다.
  • 예시 제공: '토스처럼 깔끔하게' 같은 참고 서비스를 적으면 디자인 수정이 줄어듭니다.
  • 한 번에 묶기: 버튼 색, 문구, 간격 같은 작은 수정은 모아서 한 메시지로.

로그인·DB가 필요할 때

회원가입, 저장, 관리자 페이지가 필요하면 수파베이스(Supabase)를 연결해야 합니다. 러버블 안에서 연동 버튼을 누르면 설정이 자동으로 진행됩니다.

  • 연동: 수파베이스 무료 계정을 만들고 러버블에서 Connect. 테이블은 채팅으로 만들어 달라고 하면 됩니다.
  • 권한: 데이터 공개 범위(RLS)를 '본인 데이터만' 으로 해 달라고 명시하세요. 기본값이 열려 있을 수 있습니다.
  • 한계: 결제, 외부 API 연동은 되지만 오류가 나면 코드를 봐야 합니다. 이 단계부터는 개발자와 같이 보는 편이 빠릅니다.

자주 묻는 질문

러버블은 코딩을 전혀 몰라도 되나요?

랜딩페이지와 간단한 폼까지는 됩니다. 로그인·결제·외부 연동부터는 기본 개념을 알아야 오류를 풀 수 있습니다.

한국어로 요청해도 되나요?

네. 한국어 요청을 잘 이해합니다. 화면 문구도 한국어로 나옵니다.

크레딧은 얼마나 빨리 소진되나요?

메시지마다 차감됩니다. 요구사항을 길게 한 번에 적고 수정을 묶으면 절반 이하로 줄일 수 있습니다.

만든 앱을 실제 서비스로 써도 되나요?

됩니다. 내 도메인 연결은 Pro부터이고, 데이터 권한 설정을 반드시 확인하세요.

코드를 가져올 수 있나요?

깃허브 연동으로 전체 코드를 내보낼 수 있어 나중에 개발자가 이어서 작업할 수 있습니다.
