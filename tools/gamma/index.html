감마란

감마(Gamma)는 주제 한 줄이나 긴 글을 넣으면 슬라이드 구성, 디자인, 이미지까지 한 번에 만들어 주는 AI 프레젠테이션 도구입니다. 결과물은 웹 링크로 바로 공유하거나 파워포인트·PDF로 내보낼 수 있고, 같은 방식으로 문서와 한 페이지 웹사이트도 만듭니다.

국내에서는 감마, 감마 AI, 감마앱으로 검색되고, 대학생 과제 발표와 직장인 보고서 초안 용도로 가장 많이 쓰입니다. 한국어 UI를 제공하고 한국어 생성 품질이 안정적이라 해외 AI 도구 중 진입 장벽이 가장 낮은 편입니다.

사용법 5단계

  1. 가입gamma.app에서 구글 계정으로 가입. 가입 시 무료 크레딧이 지급됩니다.
  2. 만들기 방식 선택'생성'은 주제 한 줄로, '붙여넣기'는 이미 쓴 글로, '가져오기'는 기존 PPT·문서로 시작합니다.
  3. 개요 확인AI가 만든 슬라이드 개요를 먼저 보여 줍니다. 여기서 순서와 분량을 고치는 것이 가장 효율적입니다.
  4. 테마 선택 · 생성테마를 고르면 디자인과 이미지가 붙은 슬라이드가 완성됩니다. 1분 정도 걸립니다.
  5. 편집 · 내보내기카드 단위로 텍스트·이미지를 수정. 공유 링크, PPTX, PDF 중 선택해 내보냅니다.

국내 크리에이터가 올린 가이드 영상입니다. 글로 이해가 안 되는 화면 조작은 영상으로 확인하세요.

한국어 PPT 품질 테스트

'AI 도구 도입 제안서'라는 한 줄과 2,000자 보고서 원문 두 가지로 10장짜리 발표 자료를 만들어 봤습니다.

  • 주제 한 줄: 구성이 논리적이고 문장이 자연스럽습니다. 다만 내용이 일반적이라 수치·사례는 직접 넣어야 합니다.
  • 원문 붙여넣기: 원문 구조를 잘 살립니다. 긴 문단은 자동으로 불릿으로 쪼개 줍니다.
  • 이미지: AI 생성 이미지가 주제와 잘 맞습니다. 한국 특유의 장면은 어색할 수 있어 직접 올리는 편이 낫습니다.

파워포인트 내보내기 주의점

PPTX로 내보낼 때 폰트와 일부 레이아웃이 바뀝니다. 발표 직전 내보내기보다 미리 확인하는 것이 안전합니다.

  • 폰트: 감마 기본 폰트가 PC에 없으면 대체되며 줄바꿈이 밀립니다. 내보내기 후 한 번 열어 확인하세요.
  • 애니메이션: 감마의 전환 효과는 PPTX에 포함되지 않습니다.
  • 대안: 발표 자체를 감마 웹 링크로 하면 디자인이 그대로입니다. 인터넷만 되면 이쪽이 깔끔합니다.

자주 묻는 질문

감마는 무료로 쓸 수 있나요?

가입 시 무료 크레딧이 지급되고 크레딧 안에서 생성·편집·내보내기가 됩니다. 무료 400크레딧은 1회 지급이라 충전되지 않고 워터마크가 붙습니다. 유료는 Plus 월 $12(연간 $9)부터입니다.

한국어로 만들어도 자연스럽나요?

네. 한국어 UI를 지원하고 생성 문장도 자연스럽습니다. 수치와 사례는 직접 채워 넣는 것이 좋습니다.

파워포인트로 내보낼 수 있나요?

PPTX와 PDF 내보내기가 됩니다. 폰트와 일부 레이아웃이 바뀔 수 있으니 내보낸 뒤 확인하세요.

기존 PPT를 올려서 디자인만 바꿀 수 있나요?

가져오기 기능으로 PPT·워드·노션 문서를 올리면 감마 디자인으로 다시 구성해 줍니다.

캔바와 뭐가 다른가요?

감마는 내용에서 디자인을 자동으로 만드는 쪽, 캔바는 디자인을 직접 만지는 쪽입니다. 초안 속도는 감마, 완성도 편집은 캔바입니다.
