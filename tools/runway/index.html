런웨이란

런웨이(Runway)는 텍스트나 이미지에서 영상을 만드는 Gen 시리즈 모델로 알려진 AI 영상 생성 서비스입니다. 영상 생성 외에 배경 제거, 특정 부분만 움직이게 하는 모션 브러시, 카메라 컨트롤, 립싱크 같은 편집 도구가 한 작업 공간에 있어 생성부터 후반 작업까지 이어서 할 수 있습니다.

국내에서는 런웨이, 런웨이ML, 런웨이 젠으로 검색되고, 클링·피카와 함께 '영상 생성 3대장'으로 비교되는 글이 많습니다. 공식 한국어 사이트가 있어 가입과 결제가 편합니다.

사용법 5단계

  1. 가입runwayml.com에서 구글 계정으로 가입. 가입 시 1회성 무료 크레딧이 들어옵니다.
  2. 모델 선택최신 Gen 모델을 기본으로. 빠른 테스트는 Turbo 계열, 최종본은 상위 모델로 돌립니다.
  3. 이미지 또는 텍스트 입력결과 통제가 중요하면 이미지→영상을 추천. 첫 프레임 이미지를 넣고 움직임만 영어로 짧게 적습니다.
  4. 카메라·길이 설정카메라 컨트롤에서 줌·팬 방향을 지정. 5초로 시작해 마음에 들면 10초로 늘립니다.
  5. 생성 · 편집 · 내보내기결과물을 바로 업스케일하거나 배경 제거 도구로 다듬은 뒤 MP4로 저장합니다.

국내 크리에이터가 올린 가이드 영상입니다. 글로 이해가 안 되는 화면 조작은 영상으로 확인하세요.

Gen 모델 고르는 법

런웨이는 여러 세대의 Gen 모델을 함께 제공하고, 모델마다 크레딧 소모와 특징이 다릅니다. 2026년 11월 요금 페이지 기준 Gen-4.5는 초당 12크레딧이고, Gen-4 Turbo는 같은 625크레딧으로 약 104초를 만들 수 있어 테스트용으로 저렴합니다.

편집 도구 활용

런웨이가 다른 생성 툴과 가장 다른 점은 편집 도구입니다. 생성한 영상을 외부 툴 없이 바로 다듬을 수 있습니다.

  • 배경 제거: 그린스크린 없이 인물만 분리. 유튜브 썸네일 영상에 유용합니다.
  • 카메라 컨트롤: 생성 전에 줌·팬·틸트 방향과 강도를 지정합니다. 프리셋 방식의 힉스필드보다 자유도가 높습니다.
  • 확장(Extend): 생성된 영상을 이어서 늘립니다. 10초 이상 장면을 만들 때 씁니다.

자주 묻는 질문

런웨이는 무료로 쓸 수 있나요?

가입 시 1회성 무료 크레딧이 지급되고 충전되지 않습니다. 125크레딧 1회 지급이고 워터마크가 붙습니다.

한국어로 쓸 수 있나요?

공식 한국어 사이트가 있어 가입·결제가 편합니다. 프롬프트는 영어가 더 안정적입니다.

클링과 뭐가 다른가요?

런웨이는 편집 도구와 속도, 클링은 인물 동작과 가격이 강점입니다. 생성 후 다듬는 작업이 많으면 런웨이입니다.

크레딧은 얼마나 빨리 소진되나요?

모델과 길이에 따라 다릅니다. 상위 모델 10초 생성 몇 번이면 Standard 월 크레딧의 상당 부분이 소진됩니다.

상업적으로 써도 되나요?

유료 플랜 결과물은 상업적 이용이 가능합니다. 무료 플랜은 워터마크가 있어 실질적으로 테스트용입니다.
