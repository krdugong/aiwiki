메이크란

메이크(Make)는 트리거와 동작 모듈을 선으로 이어 자동화 시나리오를 만드는 노코드 도구입니다. 구글 시트, 노션, 슬랙, 오픈AI 등 수천 개 앱 모듈이 있고, 각 모듈이 실행될 때마다 오퍼레이션 1회로 계산해 과금합니다.

국내에서는 메이크, 메이크닷컴으로 검색되고, n8n보다 쉽게 시작하려는 마케터와 소상공인이 많이 씁니다. 한국어 UI는 없지만 메뉴가 단순합니다.

사용법 5단계

  1. 가입make.com에서 구글 계정으로 가입. 무료 플랜에 월 1,000크레딧(구 오퍼레이션)이 있습니다.
  2. 시나리오 생성첫 모듈로 트리거(폼 제출·스케줄·웹훅)를 놓습니다. 템플릿에서 비슷한 시나리오를 가져오면 빠릅니다.
  3. 모듈 연결다음 동작(시트 행 추가, 슬랙 메시지 등)을 잇고 앞 모듈의 데이터를 드래그해 매핑합니다.
  4. 테스트'Run once'로 1회 실행해 각 모듈의 입력·출력을 봅니다.
  5. 스케줄·활성화실행 주기를 정하고 켭니다. 오퍼레이션 사용량을 첫 주에 확인해 요금을 예측하세요.

영상으로 보는 사용법

국내 크리에이터가 올린 가이드 영상입니다. 글로 이해가 안 되는 화면 조작은 영상으로 확인하세요.

오퍼레이션 요금 계산법

메이크 비용은 시나리오 설계가 좌우합니다. 같은 일을 해도 모듈 수와 실행 횟수에 따라 몇 배 차이가 납니다.

  • 계산: 1회 실행 시 거치는 모듈 수 × 실행 횟수. 모듈 4개 시나리오를 하루 50번 돌리면 월 6,000 오퍼레이션.
  • 절약: 필터로 불필요한 실행을 앞에서 끊고, 반복 처리는 배열로 한 번에 넘깁니다.
  • 주의: 15분마다 폴링하는 트리거는 데이터가 없어도 오퍼레이션을 씁니다. 웹훅 트리거로 바꾸면 0입니다.

AI 모듈 활용

오픈AI·앤트로픽 모듈로 시나리오 중간에 요약·분류·초안 작성을 넣을 수 있습니다.

  • 문의 분류: 폼 제출 → AI가 카테고리 판단 → 담당자별 슬랙 채널로 분기.
  • SNS 초안: 블로그 RSS → AI가 인스타 문구 생성 → 노션에 저장 후 검수.
  • 비용: AI 모듈도 오퍼레이션 1회 + API 사용료 별도. 긴 프롬프트는 API 비용이 더 큽니다.

자주 묻는 질문

메이크는 무료로 쓸 수 있나요?

월 1,000크레딧 무료 플랜이 있고 유료는 Core 연간 월 $9부터입니다. 간단한 시나리오 1~2개는 비용 없이 돌아갑니다.

오퍼레이션이 뭔가요?

시나리오 안 모듈이 1번 실행되는 단위입니다. 모듈 4개 시나리오가 1번 돌면 4 오퍼레이션입니다.

n8n과 뭐가 다른가요?

메이크는 쉽고 시각적, n8n은 자유도와 AI 통합, 셀프호스팅 무료가 강점입니다. 입문은 메이크, 확장은 n8n입니다.

카카오톡·네이버와 연동되나요?

공식 모듈은 없고 HTTP 모듈로 API를 직접 호출해야 합니다. 텔레그램·슬랙은 공식 모듈이 있습니다.

한국어 UI가 있나요?

없습니다. 다만 메뉴가 단순하고 한국어 튜토리얼이 많습니다.
