하이루오란

하이루오 AI(Hailuo AI)는 중국 AI 기업 미니맥스가 운영하는 영상 생성 서비스입니다. 텍스트 설명만으로 장면을 구성하는 능력이 좋아 스토리형 콘텐츠에 많이 쓰이고, 인물 사진을 참조로 넣어 같은 얼굴을 여러 컷에 유지하는 기능이 있습니다.

국내에서는 하이루오, 하이루오 AI, 미니맥스로 검색되고 힉스필드·클링과 비교하는 글이 늘고 있습니다. 한국어 UI가 있어 영어가 부담스러운 입문자에게 자주 추천됩니다.

사용법 5단계

  1. 가입hailuoai.video에서 구글 계정으로 가입. 언어를 한국어로 바꾸면 메뉴가 한글로 나옵니다.
  2. 모드 선택텍스트→영상, 이미지→영상, 인물 참조 중 선택. 같은 캐릭터가 여러 컷에 나오면 인물 참조를 씁니다.
  3. 프롬프트 작성장면, 피사체, 조명, 분위기 순서로 영어 한두 문장. 한국어 입력도 되지만 영어가 더 안정적입니다.
  4. 길이·해상도 설정짧은 길이·기본 해상도로 먼저 테스트하고, 마음에 들면 고해상도로 재생성합니다.
  5. 생성 · 다운로드대기열 후 생성. MP4 저장 뒤 캡컷에서 컷을 이어 붙입니다.

영상으로 보는 사용법

국내 크리에이터가 올린 가이드 영상입니다. 글로 이해가 안 되는 화면 조작은 영상으로 확인하세요.

텍스트→영상 프롬프트 팁

같은 장면을 프롬프트 구조만 바꿔 10회 생성해 봤습니다. 결과 차이가 가장 컸던 요소를 정리합니다.

  • 조명 명시: 'golden hour', 'soft studio light'처럼 조명을 적으면 분위기가 확 달라집니다.
  • 동작은 하나만: 한 프롬프트에 동작을 두 개 넣으면 섞입니다. 컷당 동작 하나.
  • 카메라는 간단히: 'slow push in' 정도만. 복잡한 카메라 지시는 무시되는 경우가 많습니다.

인물 참조로 캐릭터 유지하기

인물 사진 1장을 참조로 등록하면 여러 컷에 같은 얼굴이 나옵니다. 스토리형 쇼츠에서 가장 유용한 기능입니다.

  • 사진 조건: 정면, 밝은 조명, 얼굴이 화면의 30% 이상.
  • 한계: 옷과 머리 모양은 바뀔 수 있습니다. 프롬프트에 옷 색을 적어 고정하세요.
  • 크레딧: 참조 생성은 모델·옵션에 따라 소모량이 다르니 생성 전 표시되는 크레딧을 확인하세요.

자주 묻는 질문

하이루오는 무료로 쓸 수 있나요?

무료 플랜이 있지만 720p와 워터마크 제한이 있습니다. 유료는 Standard 정가 $14.99, 프로모션 $9.99부터입니다. 워터마크가 있고 대기열이 깁니다.

한국어 UI가 있나요?

네, 설정에서 한국어로 바꿀 수 있습니다. 프롬프트는 영어가 더 안정적입니다.

힉스필드와 뭐가 다른가요?

하이루오는 텍스트로 장면을 만드는 쪽, 힉스필드는 이미지에 카메라 워크를 입히는 쪽이 강합니다.

같은 캐릭터로 여러 컷을 만들 수 있나요?

인물 참조 기능으로 가능합니다. 옷과 머리는 프롬프트로 고정해야 합니다.

상업적 이용이 가능한가요?

유료 플랜 결과물은 가능합니다. 무료 플랜은 워터마크가 있고 조건을 확인해야 합니다.
