n8n란

n8n은 노드를 선으로 이어 '폼 제출이 오면 → AI로 분류하고 → 구글 시트에 쓰고 → 슬랙에 알린다' 같은 자동화를 만드는 오픈소스 워크플로 도구입니다. 수백 개 앱 연동 노드와 함께 챗GPT·클로드·제미나이를 부르는 AI 노드가 내장돼 있어, AI 에이전트 자동화를 만드는 데 가장 많이 쓰입니다.

국내에서는 n8n 자동화, n8n 강의로 검색량이 크게 늘었고, 유튜브와 인프런에 한국어 강의가 많습니다. 직접 서버에 설치하면 무료라 소규모 팀과 1인 사업자가 선호합니다.

사용법 5단계

  1. 시작 방식 선택빠르게 시작하려면 n8n Cloud 무료 체험, 비용 0원이 목표면 셀프호스팅(도커·레일웨이 등).
  2. 첫 워크플로트리거 노드(폼·웹훅·스케줄)를 놓고 다음 동작 노드를 잇습니다. 템플릿 갤러리에서 비슷한 걸 가져오면 빠릅니다.
  3. AI 노드 연결OpenAI 또는 Anthropic 노드에 API 키를 넣고 '이 문의를 영업/지원/스팸으로 분류'처럼 프롬프트를 작성합니다.
  4. 테스트노드마다 '실행' 버튼으로 입력·출력을 확인합니다. 오류는 대부분 데이터 형식 문제입니다.
  5. 활성화·모니터링워크플로를 Active로 바꾸고 실행 기록에서 실패 건을 봅니다. 실패 시 알림 워크플로를 하나 더 두면 안전합니다.

한국에서 많이 쓰는 자동화 예시

국내 사용자들이 실제로 만드는 워크플로 유형입니다. 템플릿을 참고해 변형하면 됩니다.

  • 뉴스·블로그 요약 알림: RSS → AI 요약 → 텔레그램·슬랙. 가장 많이 만드는 첫 워크플로.
  • 문의 자동 분류: 구글 폼·이메일 → AI 분류 → 노션·시트 기록 → 담당자 알림.
  • 콘텐츠 자동 생산: 키워드 시트 → AI 초안 → 워드프레스 임시 저장. 이 사이트의 뉴스 수집 파이프라인도 이 구조입니다.
  • 카카오·네이버 연동: 공식 노드가 없어 HTTP Request 노드로 API를 직접 호출합니다.

자주 묻는 질문

n8n은 무료인가요?

직접 서버에 설치하면 무료(서버비 별도)이고, 클라우드는 체험 후 월 요금입니다.

코딩을 몰라도 되나요?

기본 워크플로는 노드 연결만으로 됩니다. 데이터 형식 변환과 오류 처리에서 약간의 코드(자바스크립트)가 도움이 됩니다.

카카오톡 알림을 보낼 수 있나요?

공식 노드는 없지만 카카오 API를 HTTP Request 노드로 호출하면 됩니다. 텔레그램·슬랙은 공식 노드가 있어 더 쉽습니다.

메이크와 뭐가 다른가요?

n8n은 자유도와 AI 통합, 셀프호스팅이 강점이고 메이크는 입문이 쉽고 시각적입니다. 장기 비용은 n8n 셀프호스팅이 가장 낮습니다.

AI 모델 비용은 별도인가요?

네. OpenAI·Anthropic API 키를 직접 넣고 사용량만큼 해당 회사에 결제합니다.
