마누스란

마누스(Manus)는 '이 분야 경쟁사 10곳을 찾아 가격·기능을 표로 정리하고 슬라이드로 만들어 줘' 같은 요청을 받으면 스스로 검색하고 사이트를 열어 보고 파일을 만들어 결과물을 내놓는 범용 AI 에이전트입니다. 작업 화면을 실시간으로 볼 수 있어 중간에 방향을 바꿀 수 있습니다.

국내에서는 마누스로 검색되고(매너스는 드문 표기), 2025년 초 공개 당시 '일을 대신하는 AI'로 화제가 됐습니다. 젠스파크, 챗GPT 에이전트와 비교되는 글이 많습니다.

사용법 5단계

  1. 가입manus.im에서 구글 계정으로 가입. 무료 플랜은 매일 300크레딧이 갱신됩니다.
  2. 작업 정의목적, 범위, 결과물 형식(표·보고서·슬라이드), 기준(예: 한국 시장, 2026년 기준)을 한 번에 적습니다.
  3. 진행 확인에이전트가 검색·열람·정리하는 과정이 실시간으로 보입니다. 방향이 틀리면 즉시 멈추고 수정합니다.
  4. 결과물 검토완성 파일을 내려받아 수치와 출처를 확인합니다. 출처 링크를 같이 달아 달라고 하면 검증이 쉽습니다.
  5. 다듬기·재사용문체를 다듬고, 잘 된 지시문은 저장해 다음 조사에 재사용합니다.

자주 묻는 질문

마누스는 무료로 쓸 수 있나요?

매일 300크레딧이 갱신됩니다. 유료는 월 $20(연간 $17, 4,000크레딧)부터입니다. 간단한 조사 몇 건 수준입니다.

챗GPT와 뭐가 다른가요?

챗GPT는 답을 주고, 마누스는 브라우저를 열어 조사하고 파일을 만들어 일을 끝냅니다. 여러 단계 업무에 차이가 큽니다.

한국어로 시켜도 되나요?

네. 지시는 잘 이해합니다. 결과물 문체는 번역투가 섞여 마지막 다듬기가 필요합니다.

결과를 믿어도 되나요?

출처 링크를 같이 달아 달라고 요청하고 수치는 직접 확인하세요. 특히 가격·통계는 검증이 필요합니다.

회사 계정 정보를 넘겨도 되나요?

권하지 않습니다. 로그인이 필요한 작업은 공개 자료 범위로 제한하세요.
